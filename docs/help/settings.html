Settings

Every option of SQL Prompter > Settings..., page by page, with its default.

Changes apply at once; there is no restart. The file is %APPDATA%\SqlPrompter\settings.json; a member missing from it keeps its default and a broken file is replaced by the defaults (and logged) until the next save. The window follows the theme of SSMS.

Updates

OptionDefaultEffect
Check for a new versiononOnce a day, a little after SSMS starts, one anonymous HTTPS request to api.github.com for the latest release of the repository. It sends nothing about you, your computer or your queries; it runs in the background and an error or missing network is ignored. A newer version opens a window; nothing is installed without your click. SQL Prompter > Help > Check for Updates checks at any time, whatever this option says.

The choices you make in that window (a skipped version, a postponed day, the day of the last check) are stored in the settings file.

Import / Export

ButtonEffect
Export settings...Saves the settings file (.json). Unsaved changes in the window are not included; press Apply first.
Import settings...Reads a SQL Prompter .json or a SQL Prompt .settings file and applies what this extension supports (a report lists what was and was not applied). Unsaved changes in the window are dropped. From SQL Prompt it takes suggestions on/off, commit keys, alias options and custom aliases (Enter and Tab always insert here).
