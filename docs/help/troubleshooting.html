Troubleshooting

Where the files and the log are, how to see the installed version, and the known limits.

Log and version

  • SQL Prompter > Help > Open Log opens %LOCALAPPDATA%\SqlPrompter\sqlprompter.log. It records metadata loading, the result of the compatibility check and errors; it never holds passwords or script text. It is trimmed at 5 MB.
  • The first line of a session says SQL Prompter 0.200.xx loaded. That is the version of the installed extension; the same number is in Extensions > Manage Extensions. The next lines say which SSMS build was found and how many of the undocumented requirements the extension relies on were found.
  • SQL Prompter > Help > Check for Updates compares the installed version with the latest release.
  • SQL Prompter > Help > About shows the installed version, the SSMS build, the log and settings paths and the result of the last update check. Copy diagnostics puts the version, the SSMS build and the compatibility result on the clipboard, ready to paste into a bug report.

Files

FileHolds
%APPDATA%\SqlPrompter\settings.jsonAll settings, the formatting styles, the coloring rules and the update decisions.
%APPDATA%\SqlPrompter\Snippets\The personal snippets (or the folder set in the settings).
%APPDATA%\SqlPrompter\usage.jsonThe counts that rank the suggestions.
%APPDATA%\SqlPrompter\history.jsonl, tabhistory.jsonl, tabs.jsonQuery history, the history of tabs and their versions, the tabs to restore.
%LOCALAPPDATA%\SqlPrompter\sqlprompter.logThe log.
%LOCALAPPDATA%\SqlPrompter\updates\A downloaded update until it is installed (deleted at the next start).

Nothing is sent anywhere. Passwords are never stored. To start over, close SSMS and delete or rename the file you want to reset.

Installing and removing

  • Install: close SSMS and double-click SqlPrompter.Ssms.vsix. A new version installs over the old one. For an update from inside SSMS the installer waits until SSMS is closed.
  • Remove: close SSMS and run Uninstall SQL Prompter.cmd from the Uninstall folder of the extension (search %LOCALAPPDATA%\Microsoft\SSMS\22.0_*\Extensions for the file name). It asks whether to delete your settings, snippets, history and log too (they are kept by default). By hand: VSIXInstaller.exe /uninstall:SqlPrompter.0d66644a-dd92-4b87-ae9d-5d20a2df11c6 from the Common7\IDE folder of SSMS.
  • If SSMS says after a removal that a package did not load, it still holds the old registration: run SSMS.exe /updateconfiguration from the Common7\IDE folder while SSMS is closed.

Common questions

SymptomCheck
The list shows no tables or columns.Metadata loads in the background when a window is activated; right after connecting to a database the first try can be empty. Try again after a moment, or run Refresh Metadata. A window signed in with Microsoft Entra ID gets keywords and functions only. The log says whether the metadata loaded.
A new table or column is missing.Running a script that creates, alters or drops objects refreshes within a few seconds; other changes are noticed after at most 30 seconds, or use Refresh Metadata.
The built-in SSMS list appears.Enable suggestions is off, or SQL Prompter has switched itself off for that window; look at the log.
The list does not open at some place.It is not offered inside strings, comments and numbers. Ctrl+Space opens it elsewhere.
A key (F12, Shift+F5, ...) does nothing.The default key is set only when it is free. Look in Tools > Options > Environment > Keyboard for the command (names start with SQLPrompter.) and bind a key.
A restored tab is not connected.A tab that used a SQL login needs the password, which is never stored; see History and tabs.
Check for Updates says the version could not be found.The network may be unreachable, or the releases of the repository are not public. The log has the reason.
Typing misbehaves with Run the list myself while typing.Turn that experimental option off.

Known limits

  • The SSMS API is unsupported. The extension relies on undocumented parts of SSMS 22. At each start it probes them (the compatibility check). When one is missing in a newer build, only the features that need it are switched off (the connection of the window, opening windows, restoring tabs, the results grid, the execute hook, the Ctrl+Left/Right keys) and a message names them once. It was tested with SSMS 22.11 (build 22.11.12328.437).
  • Built-in functions do not have parameter info; columns of tables in other databases and of names with a server part (beyond the four-part case) are not completed.
  • Entra ID connections have no metadata (keywords and functions only).
  • A snippet body box has no undo.
  • Not every SQL Prompt option has a counterpart; the import of settings and styles reports what was left out.
