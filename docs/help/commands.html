Commands and keys

Every command of the SQL Prompter menu, the keys that come with the extension, and the keys of the suggestion list.

The SQL Prompter menu

The menu is under Extensions by default; Extensions > Customize Menu moves it to the menu bar. Items marked R are in the Refactor submenu. Every command is also in the quick actions popup, and all of them can be bound to a key in Tools > Options > Environment > Keyboard (command names start with SQLPrompter.).

Commands that cannot be used at the moment are grayed out: for example the run and refactoring commands when no query editor is active, the selection commands when nothing is selected, the commands that need a database when the window is not connected, and Copy As IN list when the grid selection covers several columns. A grayed command run by its key does nothing.

A default key is set once, and only when the key is free; if you remove or change it, your choice is kept. Ctrl+Shift+F5 takes over the key from the command that SSMS binds to it. Reopen Closed Query Tab uses the first free of Ctrl+Shift+T (Go To File in SSMS), Ctrl+Alt+T (Template Explorer) and Ctrl+Shift+Alt+T.

Other places with commands

  • Tab context menu: Tab Color with the environments and Edit Environments....
  • Results grid context menu: Script As Temp Table, Copy as, Open in Excel.
  • Toolbar: SQL History opens the query history. SSMS keeps a new toolbar hidden until it is turned on; SQL Prompter shows it once after the first install.
  • Light bulb in the editor margin and Ctrl+.: the quick fixes of the code analysis.
  • Tap of Ctrl: the quick actions popup.
